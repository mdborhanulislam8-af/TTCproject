TTC JOB SHEET 02 - FULL PROJECT
================================

Project: Create a website for “TTC” using HTML, CSS & JavaScript.

FILES
-----
index.html   -> Home page
about.html   -> About Us page
contact.html -> Contact Us page
faq.html     -> FAQ page
css/style.css
js/script.js

FEATURES REQUIRED BY THE JOB SHEET
-----------------------------------
- 4-page website
- Full-width 3-image scrolling banner
- Band/program details
- Members profile
- Fan feedback
- Gallery with 6 items
- About page with 3 staff profiles and company image
- Contact form
- Email validation
- Mobile number validation: digits only, exactly 11 digits
- Google map integration
- FAQ with 5 collapsible questions using JavaScript
- Full-width navigation menu with mouse hover effect
- Confirmation popup after contact form submission
- Bootstrap CSS framework
- Custom unordered-list CSS styles included in style.css
- External link using target="_blank"
- Current date & time using JavaScript
- Navigation links between all pages

RUN
---
1. Extract the project folder.
2. Open index.html in a browser.
3. Internet connection is required for Bootstrap CDN, Google Maps and remote images.
4. For XAMPP, copy the ttc-job2 folder into htdocs and open:
   http://localhost/ttc-job2/

NOTE
----
The project uses Bootstrap 5 via CDN and does not use jQuery.
Remote Unsplash images are used so no image download/setup is required.
